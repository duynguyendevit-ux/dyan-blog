# Chào mừng! 👋

Đây là blog cá nhân của mình, được xây dựng bằng [Quartz](https://quartz.jzhao.xyz) - một static site generator tuyệt vời.

## Tại sao chọn Quartz?

- ⚡️ **Siêu nhanh** - static site, load tức thì
- 📝 **Markdown thuần** - viết dễ dàng, không phức tạp
- 🔗 **Wikilinks** - liên kết giữa các bài viết
- 🎨 **Đẹp mắt** - design clean, đọc dễ chịu
- 🌐 **Deploy miễn phí** - GitHub Pages, Netlify, Vercel
