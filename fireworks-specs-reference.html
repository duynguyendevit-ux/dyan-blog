    Fireworks Mortar Racks & Fusing: Technical Specifications

    Reference guide chi tiết về kích thước, phân loại và đặc điểm kỹ thuật của mortar racks và fusing systems cho 3D modeling.

    Source: Skylighter’s Mortar Rack & Fusing Guide

    🎯 Mortar Tubes (Ống phóng)

    Materials & Properties

    MaterialCharacteristicsUse CasesCost
    HDPE PlasticLightweight, impact-resistantConsumer fireworks, reusable$
    FiberglassDurable, heat-resistantProfessional displays, high-use$$
    Paper (Kraft)Single-use, disposableSmall shells, budget shows$
    MetalExtremely durableSpecial applications only$$$

    Standard Dimensions

    Festival Ball Mortars (1.75” shells)

    Inner Diameter: 1.8 inches (45.7 mm)
Outer Diameter: 2.0-2.2 inches (50.8-55.9 mm)
  - HDPE: ~2.0"
  - Fiberglass: ~2.1"
  
Length: 10-12 inches (254-305 mm)
  - Standard: 10" (Skylighter PL3170)
  - Extended: 12" (better lift)
  
Wall Thickness:
  - HDPE: 0.1 inches (2.5 mm)
  - Fiberglass: 0.15 inches (3.8 mm)
  - Paper: 0.08 inches (2 mm)

Base Plug Thickness: 0.5-0.75 inches (12.7-19 mm)

    Artillery Shell Mortars (Larger sizes)

    2" Shell Mortar:
  - ID: 2.0" (5.1 cm)
  - Length: 12-15" (30.5-38 cm)
  
3" Shell Mortar:
  - ID: 3.0" (7.6 cm)
  - Length: 18-24" (45.7-61 cm)
  
4" Shell Mortar:
  - ID: 4.0" (10.2 cm)
  - Length: 24-36" (61-91 cm)

    Color Coding (Common Standards)

    • Yellow: 1.75” fiberglass (Skylighter PL3182)
    • Red: 2” HDPE
    • Green: 3” fiberglass
    • Black: HDPE standard
    • White: Paper tubes

    🔧 Mortar Racks (Giá đỡ)

    Construction Specifications

    Wooden Racks

    Wood Type: Pine, Plywood, or treated lumber
Thickness: 3/4 inch (19 mm) plywood or 1x4 boards

Base Plate:
  - Dimensions: 24" x 6" (61 x 15.2 cm) (for 6-tube rack)
  - Material: 3/4" (19 mm) plywood
  
Side Supports:
  - Height: Match mortar length + 1" (2.5 cm)
  - Spacing: 10-12" (25.4-30.5 cm) from base
  
Mortar Spacing (Center-to-Center):
  - 1.75" mortars: 3 inches (76 mm)
  - 2" mortars: 3.5 inches (89 mm)
  - 3" mortars: 4-5 inches (102-127 mm)

Fasteners:
  - Wood screws: #8 x 1.5" (3.8 cm)
  - Avoid nails near mortars
  - Countersink all screws

    Metal Racks (Skylighter PL3175)

    Frame Material: Steel tubing
  - Thickness: 1/16" (1.6 mm)
  - Square tube: 1" x 1" (2.54 x 2.54 cm)

Mortar Holders: Metal clips or rings
  - Diameter: Match mortar OD + 0.1" (2.5 mm)
  
Feet:
  - Width: 18-24" (45.7-61 cm) for stability
  - Swing-out design
  - Spike holes: 1/4" (6.4 mm) diameter

Overall Dimensions (6-tube rack):
  - Width: 18 inches (45.7 cm)
  - Height: 12 inches (30.5 cm)
  - Depth (with feet): 24 inches (61 cm)
  
Weight: ~8-10 lbs empty

    Rack Orientations & Angles

    Perpendicular Racks (Straight Up)

    Angle: 90° vertical
Mortar Tilt: 0°

Safety Orientation:
  - Rack ends perpendicular to crowd
  - If rack falls, fires away from crowd
  
Typical Setup:
  ┌─┬─┬─┬─┬─┬─┐  ← Top view
  │ │ │ │ │ │ │
  │ │ │ │ │ │ │  6 mortars
  │ │ │ │ │ │ │
  └─┴─┴─┴─┴─┴─┘
  
  Front → ⚠️ Crowd

    Fan Racks (Angled)

    Center Tube: 90° vertical
Outer Tubes: Fanned outward

Fan Angles (6-tube example):
  Tube 1: 75° (15° left of center)
  Tube 2: 82.5° (7.5° left)
  Tube 3: 90° (center)
  Tube 4: 97.5° (7.5° right)
  Tube 5: 105° (15° right)
  Tube 6: 112.5° (22.5° right)
  
Total Fan Spread: 37.5° arc
Typical Range: 30-45° total spread

Visual Pattern:
     │ ╱ ╱  ← shells spread in sky
     │╱╱
     ╱│╲
    ╱ ╲ ╲

    Anchoring Methods

    Buried Mortars

    Burial Depth: 2/3 of mortar length
  - 10" mortar → bury 6.67" (16.9 cm)
  - 12" mortar → bury 8" (20.3 cm)
  
Hole Diameter: Mortar OD + 0.5" (1.3 cm)
Backfill: Compacted soil

    Rebar Pin Anchoring

    Screw Eye Specs:
  - Size: 1/4" (6.4 mm) diameter
  - Length: 2" (5.1 cm) into wood
  - Position: Each corner of rack

Rebar Pins:
  - Diameter: 3/8" (9.5 mm)
  - Length: 18-24" (45.7-61 cm)
  - Ground penetration: 12-16" (30.5-40.6 cm)
  
Spacing: One pin can secure 2 racks end-to-end

    Swing-Out Feet (PL3175 style)

    Foot Length: 12" (305 mm)
Foot Width: 2" (51 mm)

Spike Holes:
  - Diameter: 3/8" (9.5 mm) for tent stakes
  - Position: 2" (5.1 cm) from foot ends
  
Stakes/Spikes:
  - Length: 10-12" (25.4-30.5 cm)
  - Material: Steel or aluminum

    🔥 Fuse Types & Classifications

    Physical Dimensions

    American Visco (GN1000)

    Outer Diameter: 0.2 inches (5 mm)
Core Diameter: 0.08 inches (2 mm)

Layers (outside to inside):
  1. Wax coating (waterproof)
  2. Cotton braided cover
  3. Tissue paper layer
  4. Black powder core
  
Color: Green or red outer braid
Length per roll: 50 feet (15.2 m)
Weight: ~4 oz per 50 ft

Burn Rate: 2.5 seconds/inch
Burn Temperature: ~2000°F (1093°C)

    Chinese Visco

    Outer Diameter: 0.18 inches (4.5 mm)
Core Diameter: 0.07 inches (1.8 mm)

Similar layer structure to American
Tighter braid = faster burn

Color: Green (most common)
Length per roll: 50-100 feet

Burn Rate: 1.7 seconds/inch

    Fast Visco (Cannon Fuse)

    Outer Diameter: 0.15 inches (3.8 mm)
Core Diameter: 0.1 inches (2.5 mm)

Powder core is more exposed
Less layering = faster ignition

Color: Yellow, orange, or white
Length per roll: 20-50 feet

Burn Rate: 0.25 seconds/inch (4 inches/sec)
Use: Shell leaders (fuses on shells)

    Fast Fuse (Paper Cannon Fuse)

    Construction: Paper tube + loose black powder

Tube Dimensions:
  - Outer Diameter: 0.12 inches (3 mm)
  - Inner Diameter: 0.08 inches (2 mm)
  - Wall Thickness: 0.02 inches (0.5 mm)

Paper: Kraft, natural brown
Powder Fill: 60-70% volume

Burn Rate: 0.1-0.15 seconds/inch
Speed: 6.5-10 inches/second

    Time Fuse (Green Cannon Fuse)

    Outer Diameter: 0.25 inches (6.4 mm)
Core Diameter: 0.12 inches (3 mm)

Layers:
  1. Wax/lacquer coating
  2. Thick cotton braid (2-3 layers)
  3. Tissue paper barrier
  4. Compressed black powder core
  
Color: Green, yellow, or orange
Stiffness: Semi-rigid

Burn Rate: 2.2-3.0 seconds/inch
  - Typical: 2.6 s/inch average
Consistency: Very predictable (±0.1 s/inch)

Use: Precision timing delays

    Quickmatch (GN3001)

    Tube Construction: Kraft paper pipe

Dimensions:
  - Outer Diameter: 0.4 inches (10 mm)
  - Inner Diameter: 0.3 inches (7.6 mm)
  - Wall Thickness: 0.05 inches (1.3 mm)

Contents: 5-7 strands of black match
  - Each strand: 0.04" diameter
  - Loose powder between strands

Paper Layers: 3-4 wraps kraft paper
Color: Natural brown or red (waterproof coating)

Burn Rate: "Instantaneous"
  - Actually: ~30 feet/second (9 m/s)
  - Appears instant to human eye
  
Length per roll: 100 feet (30.5 m)
Flexibility: Can bend around corners

    Foil-Taped Fast Fuse (Quickmatch Alternative)

    Base: Fast Visco or Fast Fuse
Tape: Aluminum foil duct tape

Tape Dimensions:
  - Width: 2 inches (51 mm)
  - Thickness: 0.004 inches (0.1 mm)

Construction Method:
  1. Lay fuse on tape (adhesive side up)
  2. Fold tape over to enclose fuse
  3. Press firmly to seal

Result: Creates oxygen-restricted burn tube
Burn Rate: Instantaneous (like quickmatch)
Advantage: Shippable (quickmatch is not)

    🎨 Cross-Matching & Buckets

    Cross-Matched Time Fuse

    Base Fuse: Time fuse (1/4" diameter)
Split Length: 0.5 inches each end

Black Match Strands:
  - Count: 3 strands per end
  - Length: 2 inches (5.1 cm)
  - Diameter: 0.04 inches (1 mm)
  - Source: Extracted from quickmatch

Knot Type: Clove hitch + overhand
Knot Position: Just inside split

Total Segment Length Example:
  - Desired delay: 3.3 seconds
  - Time fuse needed: 1.5 inches (3.8 cm) (at 2.2 s/in)
  - Cross-match: 0.5" (1.3 cm) each end
  - Total cut length: 2.5 inches (6.4 cm)

    Paper Buckets

    Material: Kraft paper
  - Weight: 50-60 lb kraft
  - Thickness: 0.008 inches (0.2 mm)
  - Color: Natural brown

Flat Dimensions: 3.5" x 3.5" (8.9 x 8.9 cm) square

Rolled Dimensions:
  - Form around: 0.5" (12.7 mm) dowel
  - Outer Diameter: 0.6 inches (15.2 mm)
  - Height: 1.5 inches (38 mm)
  - Wall Thickness: 0.04 inches (1 mm, ~5 wraps)

Glue: Wheat paste or white glue
Glue Strip: 0.25" (6.4 mm) along edge

String Tie:
  - Material: Waxed cotton string
  - Diameter: 1mm (#18)
  - Knot: Tight overhand or square knot
  - Position: 0.25" (6.4 mm) from bucket end

Purpose: Contains flame transfer
  - Prevents premature ignition
  - Forces burn through time fuse

    Bucket Assembly Spacing

    Time Fuse Delay Chain (6 shells, 3.3s delays):

[Ignition] → Bucket₁ → TimeFuse₁ → Bucket₂ → Shell₁
                       (1.5")
              Bucket₂ → TimeFuse₂ → Bucket₃ → Shell₂
                       (1.5")
              Bucket₃ → TimeFuse₃ → Bucket₄ → Shell₃
                       (1.5")
              [continues...]

Physical Layout on Rack:
  - Shell spacing: 3 inches (7.6 cm) center-to-center
  - Bucket + TimeFuse assembly: ~3.5 inches (8.9 cm) total
  - Route between mortars
  - Tie down every 6 inches (15.2 cm)

    📏 Shell Leader Specifications

    Standard Shell Leaders

    Material: Fast Visco (Yellow)

Length Standards:
  - 1.75" shell: 3-4 inches (7.6-10.2 cm)
  - 2" shell: 4-5 inches (10.2-12.7 cm)
  - 3" shell: 5-6 inches (12.7-15.2 cm)
  - 4" shell: 6-8 inches (15.2-20.3 cm)

Attachment Method:
  - Inserted into shell lift cup
  - Secured with tape or glue
  - Extends outside mortar top

Ignition End:
  - Fresh diagonal cut (45°)
  - Exposes powder core
  - Cut immediately before fusing

Delay Calculation:
  - 4" fast visco @ 0.25 s/in = 1 second delay
  - Plus lift time = total to ignition

    🔗 Fuse Connection Methods

    Side-by-Side Taping (Visco Chain)

    Main Chain Fuse: Chinese Visco
Shell Leader: Fast Visco

Connection Specs:
  - Parallel alignment: 1 inch (2.54 cm) minimum
  - Must be touching along full length
  - No right-angle connections (fails)

Tape Type:
  - Masking tape: 0.75" (1.9 cm) width
  - Aluminum foil tape: 2" (5.1 cm) width (preferred)
  
Tape Application:
  - Wrap tightly
  - 1.5 wraps minimum
  - Press to ensure contact

Spacing on Rack:
  - Follow mortar spacing (3" / 7.6 cm)
  - Tie down between each mortar

    Piercing Method (Quickmatch Chain)

    Main Chain: Quickmatch (10mm diameter)

Piercing Tool: Awl
  - Point diameter: 0.1 inches (2.5 mm)
  - Pierce all layers completely
  - Visual confirmation of black match

Shell Leader Insertion:
  - Fresh diagonal cut on leader
  - Insert 1 inch (2.54 cm) into quickmatch
  - Angle slightly toward black match

Securing:
  - Aluminum foil tape preferred
  - Wrap 360° around junction
  - 1.5" (3.8 cm) tape length

Tie-Down Spacing:
  - Between each mortar
  - Use waxed string
  - Prevents chain yanking on first fire

    ⚠️ Safety Specifications

    Minimum Distances

    Spectator Safety Distances (1.75" shells):
  - Minimum: 70 feet (21.3 m)
  - Recommended: 100 feet (30.5 m)

Fallout Radius:
  - Minimum clear zone: 100 feet (30.5 m)
  - 360° around firing point

Rack-to-Rack Spacing:
  - Minimum: 10 feet (3 m)
  - Preferred: 15 feet (4.6 m)

    Shell Seating

    Proper Seating:
  - Shell must rest on mortar bottom
  - No gap between shell base and plug
  - Check by pressing down

Improper Seating Effects:
  - Gap → reduced lift pressure
  - Lower burst altitude (50-70% normal)
  - Increased fire hazard ("low break")

Shell Fit Clearance:
  - 0.05-0.1 inch radial clearance
  - Too tight → stuck shell
  - Too loose → pressure loss

    📐 3D Modeling Checklist

    Mortar Rack Model Requirements

    Geometry:

    • Mortars: Correct ID/OD/length ratios
    • Spacing: Accurate center-to-center distances
    • Base plate thickness: 19mm (3/4”)
    • Fastener positions: Not intersecting mortars
    • Feet/anchoring: Functional proportions

    Materials:

    • Wood grain direction (vertical on supports)
    • HDPE: Slight sheen, dark gray
    • Fiberglass: Matte, colored (yellow/green)
    • Metal: Steel texture, slight rust optional

    Details:

    • Screw heads: Countersunk or flat
    • Rebar pins: 3/8” diameter
    • String ties: 1mm waxed cotton
    • Weathering: Optional dirt, powder residue

    Fuse Model Requirements

    Quickmatch:

    • Paper tube: 10mm OD, kraft texture
    • 3-4 visible wrap layers
    • Slight spiral seam
    • Red waterproof coating optional

    Visco Types:

    • Braided texture (bump mapping)
    • Correct diameter per type
    • Color coding accurate
    • Wax sheen on American/Time fuse

    Cross-Match Detail:

    • Split ends: Visible paper separation
    • Black match strands: 3x thin lines
    • Knot geometry: Clove hitch visible
    • String tie: 1mm cord, tight wrap

    Buckets:

    • Kraft paper: 0.2mm thick appearance
    • Rolled seam visible
    • Slight taper (hand-rolled look)
    • String tie: 2 wraps, tight knot
